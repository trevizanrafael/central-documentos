# Guia: Relatórios e Detalhes de Monitoramentos

O sistema oferece módulos de **consulta e análise** para que você possa auditar os registros realizados, acompanhar pendências e gerar documentação para fiscalizações.

---

## 1. Detalhes de Monitoramentos

Acesse pelo menu lateral em **Detalhes de Monitoramentos** ou pelo atalho na Home.

Este módulo exibe uma **listagem completa** de todos os monitoramentos realizados, com filtros para facilitar a busca:

### Filtros disponíveis
- **Período:** Filtre por data de início e data de fim.
- **PAC:** Filtre por um plano específico.
- **Resultado:** Filtre somente os "Não Conformes", somente os "Conformes" ou todos.
- **Estabelecimento:** Se sua conta tiver acesso a múltiplos locais.

### O que cada linha mostra
- Data e hora do registro
- PAC e item avaliado
- Resultado (Conforme / Não Conforme)
- Responsável pelo registro
- Status das ações corretivas/preventivas (quando aplicável)

> **Dica:** Use este módulo antes de uma auditoria do MAPA para garantir que todos os registros estejam completos e as ações pendentes estejam executadas.

---

## 2. Relatório de Monitoramentos

Acesse pelo menu lateral em **Relatório de Monitoramentos**.

Este módulo gera uma **visão consolidada** por período, ideal para reuniões de análise crítica e apresentação ao Responsável Técnico.

### Como gerar um relatório
1. Selecione o **período** (mês/ano ou intervalo de datas).
2. Selecione o **PAC** ou deixe em "Todos" para um relatório geral.
3. Clique em **Gerar**.

O relatório exibirá:
- Total de monitoramentos realizados no período
- Percentual de conformidade
- Lista de não conformidades registradas
- Status de execução das ações corretivas e preventivas

---

## 3. Monitoramento View (Visão Detalhada de um Registro)

Ao clicar em qualquer registro nos módulos acima, o sistema abre a **Visão Detalhada** daquele monitoramento específico.

Nessa tela você pode ver:
- Todos os campos preenchidos pelo operador
- A data e hora exata do registro (gerada pelo servidor)
- O nome do responsável (registrado automaticamente pelo sistema)
- O histórico das ações corretivas e preventivas com datas de execução

> **Importante:** Esta visão é **somente leitura**. Os dados não podem ser alterados após o salvamento, garantindo a integridade do registro para fins de auditoria.

---

## 4. Exportação

Os relatórios podem ser exportados. Verifique os botões de exportação na tela para as opções disponíveis (PDF, Excel, etc.).
