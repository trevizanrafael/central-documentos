# Guia: Usuários e Perfis de Acesso

O sistema possui um controle de acesso por **perfis**, permitindo que cada usuário veja e acesse apenas os módulos necessários para a sua função.

---

## 1. Perfis de Acesso

Os perfis definem **quais menus e funcionalidades** cada usuário pode usar.

Exemplos comuns de perfis:
- **Operador:** Acessa apenas o módulo de Monitoramento para registrar os apontamentos diários.
- **Supervisor:** Acessa Monitoramento, Relatórios e Detalhes de Monitoramentos.
- **Responsável Técnico:** Acesso completo a todos os módulos, incluindo PAC, Produtos e Configurações.

### Como gerenciar Perfis
1. Acesse **Perfis de Acesso** no menu lateral.
2. Clique em **+ Novo** para criar um perfil.
3. Dê um nome ao perfil (ex: "Operador de Linha").
4. Marque os **módulos** que esse perfil pode acessar.
5. Clique em **💾 Salvar**.

---

## 2. Usuários da Empresa

Gerencie quem tem acesso ao sistema na sua empresa.

1. Acesse **Usuários** no menu lateral.
2. Clique em **+ Novo** para cadastrar um novo colaborador.
3. Preencha:
   - **Nome completo**
   - **E-mail** (será o login)
   - **Perfil de Acesso** (qual perfil esse usuário terá)
   - **Senha inicial**
4. Clique em **💾 Salvar**.

O novo usuário receberá as credenciais e poderá acessar o sistema com as permissões do perfil vinculado.

---

## 3. Editando e Desativando Usuários

- Para **editar** um usuário, selecione-o na barra de navegação e altere os campos desejados.
- Para **desativar** o acesso de um colaborador que saiu da empresa, edite o usuário e remova ou altere o perfil para um perfil sem acesso (ou exclua o registro).

> **Atenção:** Nunca exclua um usuário que já realizou monitoramentos. Isso pode afetar a rastreabilidade dos registros históricos. Prefira **alterar a senha** ou **remover o perfil** para bloquear o acesso.

---

## 4. Quantos usuários posso ter?

O número de usuários disponíveis depende do **plano contratado** com a FoodTech. Caso precise de mais usuários, entre em contato com nossa equipe de suporte.
